## 📌 О проекте

**Slot Math Designer** — инструмент для математиков, геймдизайнеров и разработчиков азартных игр. Приложение позволяет конфигурировать математику ленточных слотов, гибко настраивать игровые механики (Wild, Scatters, Bonus), производить симуляции на миллионы спинов с распределением нагрузки по всем ядрам процессора и получать детальные отчеты (PAR Sheet) для подгонки RTP под целевые показатели.

## 🚀 Ключевые возможности

### 🎮 1. Конфигурация игрового поля и ставок
* **Сетка игры:** поддержка полей **5×3** и **5×4**.
* **Линии выплат (Paylines):** выбор стандартных наборов (20, 53, 54 линии) или кастомный выбор активных траекторий.
* **База расчета выплат (Payout Base):**
  * `TOTAL_BET` — множители таблицы умножаются на общую ставку.
  * `BET_PER_LINE` — классический расчет от ставки на линию.

### 🧩 2. Символы и таблица выплат (Paytable)
* Создание произвольного набора символов с уникальными ID и именами.
* Настройка выплат за комбинации от **×2 до ×5** символов на активных линиях.

### 🎡 3. Ленты барабанов (Reel Strips)
* **Ручной редактор:** независимое редактирование каждой из 5 лент.
* **🎲 Встроенный генератор барабанов:** автоматическая случайная генерация лент с **индивидуальной длиной для каждого барабана** с учетом разрешенных позиций для Wild и Scatter.
* **Анализ весов барабанов (Reel Weights):** мгновенный расчет количества и процентного вхождения каждого символа на каждой ленте.

### 🃏 4. Механики Wild и Scatter
* **Wild:**
  * Ограничение по барабанам (например, только 2, 3, 4).
  * **Expanding Wild:** расширение по вертикали на весь барабан.
  * **Sticky Wild:** удержание символа на поле на заданное количество спинов.
  * **Boom Wild:** взрыв соседних клеток по заданному радиусу и диагоналям.
* **Scatters & Bonus:**
  * Поддержка **до 2 независимых типов скаттеров** одновременно (например, `SCATTER` для фриспинов и `BONUS` для бонус-игры).
  * Оплата за общее количество на экране (Anywhere Pay) с множителями от общей ставки.
  * Фильтрация барабанов выпадения (например, только на 1, 3, 5 барабанах).

### 🎲 5. Настройки ГСЧ (RNG)
* Выбор современных генераторов псевдослучайных чисел:
  * **PCG64** (быстрый статистический стандарт по умолчанию)
  * **Mersenne Twister (MT19937)** (классический алгоритм)
  * **Philox** (счетчиковый алгоритм)
  * **SFC64** (хаотический генератор)
* Режимы инициализации:
  * **Auto / Time-based:** генерация уникального сида от наносекунд времени и энтропии ОС.
  * **Fixed Seed:** фиксация конкретного сида для 100% воспроизводимости результатов теста.

### ⚡ 6. Оптимизированная симуляция
* **Многопроцессорность (`multiprocessing`):** распределение нагрузки на все ядра CPU без блокировки графического интерфейса.
* **Щадящий режим (Throttled Batches):** симуляция порциями по 100 000 спинов с микро-паузами и сборкой мусора для защиты слабых ПК от зависания и перегрева.
* **Интерактивный контроль:** плавный прогресс-бар в реальном времени и возможность экстренной отмены расчета (кнопка `CANCEL`).

## 📊 Собираемая статистика

По завершении симуляции формируются подробные аналитические вкладки:

| Метрика | Описание |
|---|---|
| **RTP (Return to Player)** | Итоговый процент возврата игроку ($\frac{\text{Total Win}}{\text{Total Bet}} \times 100\%$). |
| **Hit Rate / Frequency** | Процент выигрышных спинов и частота выпадения выигрыша ($1 : N$). |
| **Max Win / Max Win X** | Абсолютный максимальный выигрыш за один спин и его множитель к ставке. |
| **Combinations Stats** | Детализация по каждой комбинации (символ + длина): хиты, процент выпадения, вклад в RTP. |
| **Scatters Stats** | Количество выпадений по штукам на экране (×2, ×3, ×4, ×5), выплаты и RTP вклад каждого скаттера. |
| **Symbols Stats** | Частота генерации символов + матрица весов барабанов `Symbol | Reel 1 | Reel 2 | Reel 3 | Reel 4 | Reel 5`. |
| **Win Distribution** | Распределение выплат по корзинам волатильности (`0x`, `0-1x`, `1-2x`, `2-5x`, `5-10x`, ..., `1000x+`). |
| **Wild Analytics** | Выпадения, частота спинов с Wild, количество расширенных/взорванных клеток, выигрыш по линиям с участием Wild. |

## 💾 Управление проектом и Экспорт

* **📁 Сохранение пресетов (`.json` / `.slot`):** сохранение полной математической конфигурации слота в файл и быстрая загрузка готовых моделей.
* **🔄 Автосохранение:** при закрытии программа автоматически сохраняет текущее состояние в `autosave_config.json` и восстанавливает его при следующем старте.
* **📤 Экспорт отчетов:**
  * **CSV (`.csv`):** полный математический отчет (PAR Sheet) с таблицей выплат, весами лент, пошаговой последовательностью барабанов и статистикой симуляции.
  * **JSON (`.json`):** выгрузка структуры слота и численных результатов для интеграции с игровыми серверами.
  * **PNG (`.png`):** экспорт снимка экрана интерфейса с графиками и таблицами.

## 📂 Структура репозитория

```text
├── data/
│   ├── lines_53.py            # Конфигурации линий для поля 5x3
│   └── lines_54.py            # Конфигурации линий для поля 5x4
├── engine/
│   ├── evaluator.py           # Движок подсчета выплат по линиям и скаттерам
│   ├── game_config.py         # Датаклассы базовой конфигурации
│   ├── reel.py                # Модель барабанной ленты
│   ├── rng.py                 # Фабрика генераторов случайных чисел (PCG64, MT19937, etc.)
│   ├── simulator.py           # Симулятор спинов и расчет математики
│   └── validator.py           # Валидатор математической модели на ошибки
├── export/
│   ├── csv_export.py          # Генерация подробных CSV-отчетов
│   └── json_export.py         # Сериализация модели и статистики в JSON
├── features/
│   ├── scatter.py             # Конфигурация скаттеров (Scatter 1, Scatter 2/Bonus)
│   ├── sticky.py              # Логика залипающих Wild
│   ├── wild.py                # Настройки Wild (Expanding, Boom, Sticky)
│   └── wild_processor.py      # Модификатор сетки символов при активации Wild
├── statistics/
│   └── accumulator.py         # Сборщик и мерджер метрик симуляции
├── ui/
│   └── main_window.py         # Графический интерфейс на PySide6 (Qt)
├── main.py                    # Точка входа в приложение
└── requirements.txt           # Зависимости проекта
```
